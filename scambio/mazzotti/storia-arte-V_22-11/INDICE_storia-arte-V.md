# STORIA DELL'ARTE V (Prof. Giorgio Mazzotti) · indice dei materiali · 22/11

Tutto è nella release **`mazzotti-storia-arte-V`**. Si scarica solo quello che serve con `estrai_da_release.py` (cartella `scambio/mazzotti/correzioni_22-11/` di questo ramo):

```
python3 estrai_da_release.py mazzotti-storia-arte-V "<chiave>" <cartella>
```

Per ogni lezione N servono 4 cose (chiavi esatte, con lo spazio finale dove c'è):
- **video originale del prof:** chiave della colonna «Video» (sta dentro uno degli zip grandi; la 8 è un file a parte);

- **mappe del prof (PDF):** chiave `MAPPE LEZIONE N.pdf`;
- **domande per la verifica di sbarramento:** file `DOMANDE.LEZIONE.N.xlsx` (10 domande, caricato a parte il 22/11).

Se una chiave prende anche un'altra lezione (es. «LEZIONE 1» prende anche 10-18), usa la chiave più lunga della tabella.
